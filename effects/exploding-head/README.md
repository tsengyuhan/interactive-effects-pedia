# 爆炸頭

你的五官貼滿有曲面光影的立體氣球，以近景呈現路邊紅色消防栓與綁點上方的氣球。氣球垂直上浮，左右移頭與歪頭帶動擺動；打氣會彈性膨脹，到達上限後碎成不規則薄片飄落，失去浮力的繩子垂下。主畫面不顯示真人肩頸或身體。

## 操作與限制

- 一個人正對鏡頭，讓五官完整入鏡。左右移頭或歪頭可帶動氣球甩動，頭擺正後回到綁點上方；鏡頭距離不影響場景比例。
- 點擊下方「打氣」，預設 12 下到頂；等待視覺膨脹接近上限才爆炸。碎片仍在空中或微彈時顯示「碎片飄落中…」並禁用按鈕；全部完成落地後才開放「重置」。按下後約兩秒陣風捲起並吹走碎片，再生成直立新球；這段期間不能重複點擊或打氣，沒有偵測到臉也遵守相同落地條件並能完成清場。
- 資訊面板可調背景顏色、充氣速度（0.5–2 倍，約 24–6 下）、氣球最大尺寸（場景基準球體的 1.5–4 倍，預設 2.35）。改上限保留當次氣量，僅改變球體膨脹與爆炸門檻，絕不縮小或移動消防栓來容納氣球。極大氣球可超出畫面。
- 魚眼程度為 0–1，預設 0.25；增加時五官中央放大、邊緣壓縮，調整不重置氣量或追蹤。
- 初次尚未偵測到臉時先顯示路面與消防栓。無臉、多臉或相機停幀時暫停打氣，已有的臉部貼圖保留在飄動氣球上；重新辨識後恢復即時五官。爆炸後不會因找回臉而自行復原。
- 載入、錯誤、背景分頁及充滿等待爆炸時禁用打氣；切到背景暫停動畫與推論。音效由 Web Audio 合成，不需要麥克風。
- 以單人正面為基準。側臉、遮擋、極暗光線或背景分割錯誤可能造成貼圖失真；不是完整 3D 臉部重建。

## 技術與需求

使用既有 MediaPipe Tasks Vision 0.10.14 的 ImageSegmenter 與 FaceDetector，CPU 推論、原生 WebGL 球面著色及 Canvas 2D 場景，沒有新增程式依賴。寫實街景與消防栓使用本地 AI 生成圖片，不會在執行時下載外部素材。兩模型讀取同一張最多 640 像素寬的相機快照。前景遮罩只用於臉部紋理，不將原始相機影像或身體合成至主畫布。

臉部框略留額頭與下巴，裁成固定 256×256，僅在貼圖時水平鏡像一次；五官放大包覆整顆球。遮罩空隙只由有效前景 RGB 補滿，球內 alpha 不透明。固定 512×512 離屏 WebGL 以球面法線、曲面 UV、方向光與高光呈現立體感；底端收成短氣嘴，接上小結與繩索，沒有頸部接片。

魚眼參數以 GPU uniform 調整球面取樣，0 保留基礎包覆、1 有最強中心放大。舊版方向明暗幅度小且白光加法偏多，容易顯平與褪色；新版保留底色、略增色彩濃度、加深朝光相反側並縮小高光範圍。效果仍會反映原始相機曝光與白平衡。

`scene.mjs` 依視窗尺寸安排場景基準大小、消防栓、綁點與繩長，與臉框、氣量、最大尺寸完全分離。街景與透明消防栓素材依路面校準合成，背景顏色參數用於柔和環境色調。`ground.mjs` 共用路面座標及透視投影：遠處物體變小，氣球陰影跟隨旋轉後的球心、尺寸及離地高度，離地越高越淡且柔和。陰影只畫在道路區域，爆炸後移除球影。

近景將背景等比放大 1.6 倍，消防栓較 v7 放大約 57%、氣球基準放大 50%。栓腳在原圖 y552 的人行道頂面，地面基準在 y630 的柏油，落片深度限制在路緣前方。v9 將鏡頭裁切下移，保留直立大球上方空間、栓蓋與球底間的短繩；沒有縮小球或施加單向風來湊構圖。球、消防栓與碎片陰影一致朝右前方，落片及球影仍限制在道路區域。

繩子由 13 個 Verlet 節點組成，初始垂直、固定底端並反覆約束每段長度。末端浮力與輕微零均值風力牽引球體，臉部左右位移驅動阻尼角彈簧，將慣性傳入繩索；球體方向跟隨末段繩子的張力並延遲回穩。爆炸移除浮力，繩索受重力回落，路面限制其下落。重置重新垂直綁好；失追、重獲、相機尺寸改變與切分頁會清除追蹤輸入，避免座標跳躍造成暴衝。這是輕量的繩索動力學近似，沒有消防栓碰撞、空氣流體或完整剛體模擬。

移頭輸入取原始偵測臉框中心，避免頭髮或前景範圍抵消左右位移；支援低於 750ms 的推論間隔，包含較慢的 250–400ms 模型。鏡像方向一致，停止後阻尼回彈；重新取得追蹤的第一個樣本不施加舊位移。

歪頭使用 FaceDetector 前兩個眼睛關鍵點，先將分別按影格寬高正規化的座標還原，再取鏡像傾角；0.025 弧度死區與低通濾波抑制細微抖動。首個或長間隔樣本使用當前絕對姿態，繩索本身漸進回應；缺失或異常眼點清零，重獲不沿用舊傾角，因此一秒才推論一次仍能歪頭。[MediaPipe 關鍵點座標定義](https://ai.google.dev/edge/api/mediapipe/python/mp/tasks/components/containers/keypoint/NormalizedKeypoint)、[眼睛關鍵點順序](https://github.com/google-ai-edge/mediapipe/blob/master/docs/solutions/face_detection.md)。

爆炸時凍結已著色球面，32 個隨機 Voronoi 區域形成大小不一的薄片，直接沿用球體的畫面位置與角度，並帶入繩端速度。粒子使用路面位置、深度與獨立離地高度，受重力、朝向與面積／質量相關阻力、側向飄擺及角速度阻尼影響。薄片翻面飄落，在道路上小幅彈落、滑動後受摩擦停止並平貼地面；近地有接觸影，前後片與消防栓依深度遮擋。所有落片保留直到重置，不再按固定秒數消失。這是 2.5D 地面碰撞近似，沒有薄片彼此碰撞或任意建物碰撞。

重置以每片實際 `landed`（已完成微彈）判斷，不用固定等待秒數；按鈕及函式入口均防護，最後一片落地當幀立即解鎖。其後使用單一兩秒風階段：保留爆炸狀態與凍結貼圖，喚醒落地碎片、解除畫面邊界反彈，往右上翻飛離場後才清空並綁回直立新球。失追與 resize 不提前生球。時間按真正前景經過秒數計算，內部風力細分步長；切背景暫停，不會因一般物理的 50ms 上限而讓低 FPS 清場拖成數十秒。

每次推論即釋放 mask 結果，離頁關閉模型、相機、音訊、RAF、場景圖片與 GPU 貼圖／shader／buffer，包含初始化途中離頁。街景素材遺失或載入逾時會顯示錯誤。

- 攝影機；不需麥克風。
- 建議 Chrome／Edge，需 WebGL 與硬體加速；不支援時顯示明確錯誤。手機或較舊裝置雙模型推論可能較慢，沒有保證幀率。
- 必須透過 localhost 或 HTTPS，不能直接以 `file://` 開啟。
- 模型、WASM、程式均在專案內；下載完整專案後可在本機無外網執行，不代表線上網站有 Service Worker 離線快取。

## 下載到自己的電腦

1. `git clone https://github.com/tsengyuhan/interactive-effects-pedia.git`，或由 GitHub Download ZIP 後解壓縮。
2. 雙擊專案根目錄 `start.bat`。
3. 開啟 `http://localhost:8080/effects/exploding-head/`，允許攝影機權限。
4. 確認 `libs/mediapipe/` 包含 `vision_bundle.mjs`、`wasm/`、`selfie_segmenter.tflite` 與 `blaze_face_short_range.tflite`。

## 驗證

```text
node --test effects/exploding-head/effect.test.mjs
node assets/i18n.test.js
```

46 項效果測試涵蓋既有充氣、落片、陰影、素材、相機／模型／GPU 失敗與清理回歸。新增自然落片與微彈每幀防止提早重置、失追仍受相同門檻、最後一片落地當幀解鎖；靜止 30 秒直立、完整眼點推論帶動正負傾角與回正、寬高比例與異常眼點、一秒推論間隔、重獲相反姿態及低 FPS 兩秒風階段。近景四種尺寸驗證預設最大旋轉球面邊界、栓腳與繩子；1.5→4→1.5 仍只改球體尺寸。Node 的相機與 GPU 為替身，不能代替瀏覽器視覺驗證。

v9 在 Chrome 以合成人臉與模型替身執行實際 WebGL、追蹤及物理程式：爆炸後連按仍保留 32 片，顯示停用的「碎片飄落中…」；只有 7 片落地時仍鎖定，32 片全部自然落地後才開放「重置」，之後才進入風吹階段。直頭時球角約 0；正負 0.3rad 眼線輸入分別產生約 -0.43／+0.51rad 球角，擺正後回到約 0.004rad，繩結持續相接。390×580 在 92% 氣量時球與消防栓完整，844×390 操作完整；新版 `thumb.png` 為 800×500 合成人臉直立近景。

本次動作輸入使用合成影像，未另外要求真人配合左右歪頭。v8 曾以真人相機確認五官與魚眼、以 Permissions Policy 確認相機封鎖時的繁中錯誤，以及只允許本機資源的 CSP 合成載入；這些是前版驗證範圍。素材儲存位置與生成提示詞見 [ASSETS.md](./ASSETS.md)。
