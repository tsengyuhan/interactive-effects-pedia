# 爆炸頭

你的五官貼滿有曲面光影的立體氣球，綁在路邊紅色消防栓上。氣球受浮力、柔和風力與移頭慣性擺動；打氣會彈性膨脹，到達上限後碎成不規則薄片飄落，失去浮力的繩子垂下。主畫面不顯示真人肩頸或身體。

## 操作與限制

- 一個人正對鏡頭，讓五官完整入鏡。左右移頭可帶動氣球甩動；鏡頭距離不影響場景比例。
- 點擊下方「打氣」，預設 12 下到頂；等待視覺膨脹接近上限才爆炸。同一按鈕變成「重置」，沒有偵測到臉也能重玩。
- 資訊面板可調背景顏色、充氣速度（0.5–2 倍，約 24–6 下）、氣球最大尺寸（場景基準球體的 1.5–4 倍，預設 2.35）。改上限保留當次氣量，僅改變球體膨脹與爆炸門檻，絕不縮小或移動消防栓來容納氣球。極大氣球可超出畫面。
- 初次尚未偵測到臉時先顯示路面與消防栓。無臉、多臉或相機停幀時暫停打氣，已有的臉部貼圖保留在飄動氣球上；重新辨識後恢復即時五官。爆炸後不會因找回臉而自行復原。
- 載入、錯誤、背景分頁及充滿等待爆炸時禁用打氣；切到背景暫停動畫與推論。音效由 Web Audio 合成，不需要麥克風。
- 以單人正面為基準。側臉、遮擋、極暗光線或背景分割錯誤可能造成貼圖失真；不是完整 3D 臉部重建。

## 技術與需求

使用既有 MediaPipe Tasks Vision 0.10.14 的 ImageSegmenter 與 FaceDetector，CPU 推論、原生 WebGL 球面著色及 Canvas 2D 場景，沒有新增程式依賴。寫實街景與消防栓使用本地 AI 生成圖片，不會在執行時下載外部素材。兩模型讀取同一張最多 640 像素寬的相機快照。前景遮罩只用於臉部紋理，不將原始相機影像或身體合成至主畫布。

臉部框略留額頭與下巴，裁成固定 256×256，僅在貼圖時水平鏡像一次；五官放大包覆整顆球。遮罩空隙只由有效前景 RGB 補滿，球內 alpha 不透明。固定 512×512 離屏 WebGL 以球面法線、曲面 UV、方向光與高光呈現立體感；底端收成短氣嘴，接上小結與繩索，沒有頸部接片。

`scene.mjs` 依視窗尺寸安排場景基準大小、消防栓、綁點與繩長，與臉框、氣量、最大尺寸完全分離。街景與透明消防栓素材依路面校準合成，背景顏色參數用於柔和環境色調。`ground.mjs` 共用路面座標及透視投影：遠處物體變小，氣球陰影跟隨旋轉後的球心、尺寸及離地高度，離地越高越淡且柔和。陰影只畫在道路區域，爆炸後移除球影。

繩子由 13 個 Verlet 節點組成，固定底端並反覆約束每段長度。末端浮力與柔和風力牽引球體，臉部左右位移驅動阻尼角彈簧，將慣性傳入繩索；球體方向跟隨末段繩子的張力並延遲回穩。爆炸移除浮力，繩索受重力回落，路面限制其下落。重置重新綁好；失追、重獲、相機尺寸改變與切分頁會清除追蹤輸入，避免座標跳躍造成暴衝。這是輕量的繩索動力學近似，沒有消防栓碰撞、空氣流體或完整剛體模擬。

爆炸時凍結已著色球面，32 個隨機 Voronoi 區域形成大小不一的薄片，直接沿用球體的畫面位置與角度，並帶入繩端速度。粒子使用路面位置、深度與獨立離地高度，受重力、朝向與面積／質量相關阻力、側向飄擺及角速度阻尼影響。薄片翻面飄落，在道路上小幅彈落、滑動後受摩擦停止並平貼地面；近地有接觸影，前後片與消防栓依深度遮擋。所有落片保留直到重置，不再按固定秒數消失。這是 2.5D 地面碰撞近似，沒有薄片彼此碰撞或任意建物碰撞。

每次推論即釋放 mask 結果，離頁關閉模型、相機、音訊、RAF、場景圖片與 GPU 貼圖／shader／buffer，包含初始化途中離頁。街景素材遺失或載入逾時會顯示錯誤。

- 攝影機；不需麥克風。
- 建議 Chrome／Edge，需 WebGL 與硬體加速；不支援時顯示明確錯誤。手機或較舊裝置雙模型推論可能較慢，沒有保證幀率。
- 必須透過 localhost 或 HTTPS，不能直接以 `file://` 開啟。
- 模型、WASM、程式均在專案內；下載完整專案後可在本機無外網執行，不代表線上網站有 Service Worker 離線快取。

## 下載到自己的電腦

1. `git clone https://github.com/tsengyuhan/interactive-effects-pedia.git`，或由 GitHub Download ZIP 後解壓縮。
2. 雙擊專案根目錄 `start.bat`。
3. 開啟 `http://localhost:8080/effects/exploding-head/`，允許攝影機權限。
4. 確認 `libs/mediapipe/` 包含 `vision_bundle.mjs`、`wasm/`、`selfie_segmenter.tflite` 與 `blaze_face_short_range.tflite`。

## 驗證

```text
node --test effects/exploding-head/effect.test.mjs
node assets/i18n.test.js
```

35 項效果測試涵蓋充氣門檻、追蹤暫停、相機權限與資源釋放、GPU 失敗清理、臉框與實心貼圖、薄片物理、同按鈕重置、移頭甩動，以及繩長／端點／有限值、爆後落繩、球結銜接及桌面與手機初始可見性。新增投影初態連續、球影隨動、32 片在 30／60／120 fps 落地結果接近、長時間保留／重置、素材失敗與釋放回歸。互動回歸確認 1.5→4→1.5 只改球體尺寸；失追、重置與相機尺寸改變均不調整消防栓構圖。主畫布沒有身體或原始 video。

本次 Chrome 使用合成人臉與模型替身，實際執行產品的本地圖片載入、WebGL 球面、Canvas 場景與物理程式。模擬推進 25 秒後，32 片全部落在可見柏油路面並停留，截圖可見落片；球影有／無的像素對照確認 4,315 個像素變暗，平均差約 23.4／255。新版 `thumb.png` 為 800×500，使用此合成測試臉，並非真人攝影機截圖。

另以只允許本機資源的 CSP 啟動相同合成測試，街景、消防栓、球面及充氣均正常，無瀏覽器錯誤；此項不涵蓋真人相機與模型推論。素材儲存位置與內建 image_gen 生成提示詞見 [ASSETS.md](./ASSETS.md)。

本次真人攝影機兩次開啟均回報 `NotReadableError: Device in use`，因此未完成新版真人相機驗證。前版曾以真人相機確認臉球、12 下爆炸及固定構圖，也曾確認相機 Permissions Policy 錯誤提示與只允許本機資源的 CSP 載入；這些前版結果不代表本次真人相機已通過。
