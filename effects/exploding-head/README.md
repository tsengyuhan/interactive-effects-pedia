# 爆炸頭

你的五官貼滿有曲面光影的立體氣球，繩子綁在從地板長出的小雛菊莖上。莖根固定在地面，氣球拉動時花莖彎曲、花頭傾斜，根部周圍有疏密漸變的草叢。選一個主色，兩面牆與地板自動搭配柔和色彩；球影與花影會跨牆腳投在牆面及地板。氣球垂直上浮，左右移頭與歪頭帶動花莖擺動；打氣會彈性膨脹，到達上限後碎成不規則薄片飄落，失去浮力的繩子垂下。主畫面不顯示真人肩頸或身體。

## 操作與限制

- 一個人正對鏡頭，讓五官完整入鏡。左右移頭或歪頭可帶動氣球甩動，頭擺正後回到綁點上方；鏡頭距離不影響場景比例。
- 點擊下方「打氣」，預設 12 下到頂；等待視覺膨脹接近上限才爆炸。碎片仍在空中或微彈時顯示「碎片飄落中…」並禁用按鈕；全部完成落地後才開放「重置」。按下後約兩秒陣風捲起並吹走碎片，再生成直立新球；這段期間不能重複點擊或打氣，沒有偵測到臉也遵守相同落地條件並能完成清場。
- 進度條與打氣鈕位於左下角；預設繩長與預設最大球尺寸時，場景地面會依視窗高度下移，盡量保留 16px 的球頂空間，地面最多到畫面底部上方 24px。較長繩子或自行提高最大尺寸時仍可能超出畫面。
- 資訊面板可調主色調（預設青綠）、充氣速度（0.5–2 倍，約 24–6 下）、氣球最大尺寸（場景基準球體的 1.5–4 倍，預設 2.35）。主色只改牆與地板，不改小花 PNG 或臉球顏色。改上限保留當次氣量，僅改變球體膨脹與爆炸門檻，不縮放或移動花來容納氣球。
- 繩長可調 0.6–2.5 倍，預設 1；立即重新約束原繩段，保留氣量、球大小與落片。吹風清場中也可調整；在 1920×945 桌面尺寸、預設球大小下，繩長調到上限 2.5 倍時氣球會整個超出畫面上緣（見 `team/exploding-head-v13-rope-2.5.png`），約 1.4 倍即可回到舊版酒瓶的球高度，因此上限是刻意保留的餘裕。繩子畫在小花後方，靠近綁點、被花頭遮住的那一段也會被遮住；球畫在最前面，短繩或歪頭相交時遮擋一致。
- 魚眼程度為 0–1，預設 0.25；增加時五官中央放大、邊緣壓縮，調整不重置氣量或追蹤。
- 初次尚未偵測到臉時先顯示牆角與小花。無臉、多臉或相機停幀時暫停打氣，已有的臉部貼圖保留在飄動氣球上；重新辨識後恢復即時五官。爆炸後不會因找回臉而自行復原。
- 載入、錯誤、背景分頁及充滿等待爆炸時禁用打氣；切到背景暫停動畫與推論。音效由 Web Audio 合成，不需要麥克風。
- 以單人正面為基準。側臉、遮擋、極暗光線或背景分割錯誤可能造成貼圖失真；不是完整 3D 臉部重建。

## 技術與需求

使用既有 MediaPipe Tasks Vision 0.10.14 的 ImageSegmenter 與 FaceDetector，CPU 推論、原生 WebGL 球面著色及 Canvas 2D 場景，沒有新增程式依賴。場景只載入本地透明 `flower.png`，沿用原 `balloon.mjs`；舊素材保留但不再載入或顯示。兩模型讀取同一張最多 640 像素寬的相機快照。前景遮罩只用於臉部紋理，不將原始相機影像或身體合成至主畫布。

臉部框略留額頭與下巴，裁成固定 256×256，僅在貼圖時水平鏡像一次；五官放大包覆整顆球。遮罩空隙只由有效前景 RGB 補滿，球內 alpha 不透明。固定 512×512 離屏 WebGL 以球面法線、曲面 UV、方向光與高光呈現立體感；底端收成短氣嘴，接上小結與繩索，沒有頸部接片。

魚眼參數以 GPU uniform 調整球面取樣，0 保留基礎包覆、1 有最強中心放大。舊版方向明暗幅度小且白光加法偏多，容易顯平與褪色；新版保留底色、略增色彩濃度、加深朝光相反側並縮小高光範圍。效果仍會反映原始相機曝光與白平衡。

`scene.mjs` 依視窗安排小花、綁點與繩長，與臉框、氣量、最大尺寸分離。`room.mjs` 和 `ground.mjs` 共用 `(x,z,height)`：比例 `1/(1+0.5z)`，地面深度投影係數 0.52。兩牆為 `z=0.65±0.85x`，在中央形成垂直牆角；地板高度為 0，有限前緣 `z=-1.4`，牆高 2.6。地面粒子邊界依同一斜牆深度求出，沒有額外貼圖路面。

本版改用 v13 的小花顯示高度 `unit×0.30`，基準繩長不扣除花莖高度；花根貼地，繩頂綁在花頭下方莖上。花與繩結繞根部整體旋轉，花角度取繩子第一段方向並以低通平滑，花影同步旋轉；不做莖的弧線變形。

固定點光源在 `(-0.55,-1.3,2.3)`。球的旋轉橢圓輪廓近似成世界空間直立薄面，各輪廓邊與光源形成光錐，再以同一光錐裁切有限接收面；`rayHit` 另以平面方程求最近正命中。光源在凸形房間內，因此每條光線只有一個出口接收面；牆地交界共享位置，不會把整顆影子重複貼在多面。陰影按遮擋物與接收面的距離調濃淡／柔化，跨面多邊形合併後才模糊一次以免亮縫。小花影用莖、葉與花頭輪廓近似並跟著花角度旋轉，碎片接觸影也用相同投影；爆炸後不再畫球影。這是幾何投影加輪廓近似，並非完整球體光線追蹤或真實面光源半影。

主色以 HSL 推導同色系較亮、較低彩的另一面牆，以及暖奶油地板；黑白灰保持中性色且以明度區分。各面依同一光源與法線著色，牆腳細暗線只表達接觸遮蔽。場景沒有染色覆蓋到小花或人臉。

繩子由 13 個 Verlet 節點組成，初始垂直、固定底端並反覆約束每段長度。末端浮力與輕微零均值風力牽引球體，臉部左右位移驅動阻尼角彈簧，將慣性傳入繩索；花的整體方向跟隨第一段繩子的方向並延遲回穩。爆炸移除浮力，繩索受重力回落，路面限制其下落。重置重新垂直綁好；失追、重獲、相機尺寸改變與切分頁會清除追蹤輸入，避免座標跳躍造成暴衝。這是輕量的繩索動力學近似，沒有花莖碰撞、空氣流體或完整剛體模擬。

移頭輸入取原始偵測臉框中心，避免頭髮或前景範圍抵消左右位移；支援低於 750ms 的推論間隔，包含較慢的 250–400ms 模型。鏡像方向一致，停止後阻尼回彈；重新取得追蹤的第一個樣本不施加舊位移。

歪頭使用 FaceDetector 前兩個眼睛關鍵點，先將分別按影格寬高正規化的座標還原，再取鏡像傾角；0.025 弧度死區與低通濾波抑制細微抖動。首個或長間隔樣本使用當前絕對姿態，繩索本身漸進回應；缺失或異常眼點清零，重獲不沿用舊傾角，因此一秒才推論一次仍能歪頭。[MediaPipe 關鍵點座標定義](https://ai.google.dev/edge/api/mediapipe/python/mp/tasks/components/containers/keypoint/NormalizedKeypoint)、[眼睛關鍵點順序](https://github.com/google-ai-edge/mediapipe/blob/master/docs/solutions/face_detection.md)。

爆炸時凍結已著色球面，32 個隨機 Voronoi 區域形成大小不一的薄片，直接沿用球體的畫面位置與角度，並帶入繩端速度。粒子使用地板位置、深度與獨立離地高度，受重力、朝向與面積／質量相關阻力、側向飄擺及角速度阻尼影響。薄片翻面飄落，小幅彈落與滑動後平貼地面；近地有接觸影，前後片與小花依深度遮擋。所有落片保留直到重置。這是 2.5D 地板碰撞與牆界限近似，沒有薄片彼此碰撞。

重置以每片實際 `landed`（已完成微彈）判斷，不用固定等待秒數；按鈕及函式入口均防護，最後一片落地當幀立即解鎖。其後使用單一兩秒風階段：保留爆炸狀態與凍結貼圖，喚醒落地碎片、解除畫面邊界反彈，往右上翻飛離場後才清空並綁回直立新球。失追與 resize 不提前生球。時間按真正前景經過秒數計算，內部風力細分步長；切背景暫停，不會因一般物理的 50ms 上限而讓低 FPS 清場拖成數十秒。

每次推論即釋放 mask 結果，離頁關閉模型、相機、音訊、RAF、小花圖片與 GPU 貼圖／shader／buffer，包含初始化途中離頁。小花素材遺失或載入逾時會顯示錯誤。

- 攝影機；不需麥克風。
- 建議 Chrome／Edge，需 WebGL 與硬體加速；不支援時顯示明確錯誤。手機或較舊裝置雙模型推論可能較慢，沒有保證幀率。
- 必須透過 localhost 或 HTTPS，不能直接以 `file://` 開啟。
- 模型、WASM、程式均在專案內；下載完整專案後可在本機無外網執行，不代表線上網站有 Service Worker 離線快取。

## 下載到自己的電腦

1. `git clone https://github.com/tsengyuhan/interactive-effects-pedia.git`，或由 GitHub Download ZIP 後解壓縮。
2. 雙擊專案根目錄 `start.bat`。
3. 開啟 `http://localhost:8080/effects/exploding-head/`，允許攝影機權限。
4. 確認 `libs/mediapipe/` 包含 `vision_bundle.mjs`、`wasm/`、`selfie_segmenter.tflite` 與 `blaze_face_short_range.tflite`。

## 驗證

```text
node --test effects/exploding-head/effect.test.mjs
node assets/i18n.test.js
```

56 項效果測試涵蓋相機／模型／GPU 生命週期、歪頭、花角度、落地重置、低 FPS 清場、有限牆地投影、多種視窗覆蓋、配色與 0.6–2.5 倍繩長狀態。本版量測花體與綁點，確認只載入一張小花圖，並保留資產錯誤及釋放測試。Node 的相機與 GPU 為替身，不能代替瀏覽器視覺驗證。

v13 在 Chrome 1920×945 使用合成人臉與模型替身，實際執行產品 WebGL 與 Canvas：小花無背景方框，莖根貼地、綁點清楚，花影與球影同步可見，花與球保持近景構圖。

本輪另確認 0.6／2.5 倍繩長及左右歪頭維持莖上綁點連接，珊瑚主色下小花透明度正常；爆炸後 32 片自然落地才開放重置，清場後回到新球。390×580 與 844×390 在 92% 氣量時，球、小花與操作按鈕完整；縮圖更新為 800×500 的小花版合成畫面。

本輪動作輸入與模型使用替身，並非新的真人模型測試。歷史版本已驗證牆地接縫、繩長／歪頭、落片與風吹重置；v8 曾以真人相機確認五官／魚眼，並驗證相機封鎖提示與本機 CSP 合成載入。素材用途、位置與原生成提示詞見 [ASSETS.md](./ASSETS.md)。
