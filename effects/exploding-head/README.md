# 爆炸頭

事情太多感覺頭要爆炸了。放大的五官貼滿具有曲面與反光的不透明 3D 氣球，打氣時橫向鼓起、回彈；左右移頭會帶動氣球慣性甩動。底端收成與原脖子同色的窄氣口。到達上限後，球面碎成大小不一的薄片，留下帶有不規則破口的即時無頭人像。

## 操作與限制

- 一個人正對鏡頭，完整露出頭髮與肩膀，與鏡頭保持一些距離，替膨脹留空間。
- 點擊中央下方「打氣」，預設 12 下到頂；等待視覺膨脹接近上限才爆炸。同一個按鈕會變成「重置」，沒有偵測到臉也可重玩。
- 第一次辨識到頭部時，構圖會預留最大膨脹、浮動與旋轉空間，之後身體比例固定；重置可依新站位重新校準。大幅靠近鏡頭或移出初始站位仍可能超出預留範圍。
- 資訊面板可調背景顏色、充氣速度（每次加量，0.5–2 倍，約 24–6 下）、氣球最大尺寸（原頭部的 1.5–4 倍，預設 2.35）。改最大尺寸會重新預留構圖，保留當次氣量；每次打氣不會縮放身體。
- 載入、無臉、多臉、相機停幀、錯誤及充滿等待爆炸時均禁用打氣。爆炸後改為可用的重置按鈕。失去追蹤時暫停顯示整個人像，避免漏出原頭；重新正對鏡頭後恢復即時身體，爆炸狀態不變。
- 僅以單人正面為基準。臉框搭配前景頂緣估算頭部輪廓，並非精準頭髮分割；長髮、側臉、手部遮擋、背景相近、快速移動可能殘邊或誤裁肩頸。沒有寫實血腥斷面。
- 音效由 Web Audio 合成，每次點擊啟用音訊；瀏覽器未允許音訊仍可遊玩。切到背景分頁暫停動畫與推論。

## 技術與需求

使用既有 MediaPipe Tasks Vision 0.10.14 的 ImageSegmenter 與 FaceDetector，CPU 推論、原生 WebGL 球面著色及 Canvas 2D 合成，沒有新增依賴。兩模型讀取同一張最多 640 像素寬的相機快照；貼圖直接裁切臉部偵測框、略留額頭與下巴，縮為固定 256×256，讓五官放大包覆整顆球。遮罩空隙僅由有效前景 RGB 補滿，球內 alpha 為不透明，不帶入相機背景。固定 512×512 離屏 WebGL 以球面法線、曲面 UV、方向光與高光呈現立體感，只有最外抗鋸齒邊界保留部分透明。

身體維持原比例。原下巴以下的脖子前景經中位色取樣，排除低可信背景、近黑鬍鬚及明顯冷色衣領；取不到時保留上次有效色，首次才使用中央下頰備援。shader 底端收窄並漸變為這個頸色，再用短、窄、四周羽化的純色接頸口重疊原脖子，避免放大嘴巴或下巴成寬貼片。

每次爆炸產生一組固定、不等距凹凸輪廓，局部改變頸部遮罩邊緣；破口隨人像移動、失追重獲也不重新亂跳，重置才清除，不侵蝕下方衣領與肩膀。沒有血液或寫實傷口。這仍是單人正面影像近似，並非完整 3D 人體重建；遮擋、極暗光線或與膚色相近的衣領可能影響取色與接縫。

左右追蹤位移依相機寬度正規化後驅動阻尼角彈簧，球體以頸部連接點甩動，停止後超越並回穩。角度上限約 18 度；重置、失追、切背景或相機尺寸改變均重設角擺，避免重新追蹤的座標跳躍引發暴衝。

爆炸時凍結已著色球面，32 個隨機 Voronoi 區域組成不規則薄片；旋轉中心使用多邊形面積重心。粒子採重力、朝向與相對面積／質量決定的阻力、側向飄擺及角速度阻尼，翻面會收成細線，約 4.6–6.7 秒依序淡出。這是有終端速度的薄片運動近似，未模擬碰撞或完整流體／剛體動力學。

每次推論立即釋放 mask 結果，離頁關閉模型、相機、音訊、RAF 與 GPU 貼圖／shader／buffer，包含初始化途中離頁。

- 攝影機；不需麥克風。
- 建議 Chrome／Edge，需可用的 WebGL 與硬體加速；不支援時顯示明確錯誤。手機與較舊裝置雙模型推論可能較慢，沒有保證幀率。
- 必須以 localhost 的本機伺服器或 HTTPS 開啟，不能直接使用 `file://`。
- 模型、WASM、程式均在專案內；下載完整專案後可在本機無外網執行。這不代表線上網站有 Service Worker 離線快取。

## 下載到自己的電腦

1. `git clone https://github.com/tsengyuhan/interactive-effects-pedia.git`，或由 GitHub Download ZIP 後解壓縮。
2. 雙擊專案根目錄 `start.bat`。
3. 開啟 `http://localhost:8080/effects/exploding-head/`，允許攝影機權限。
4. 確認 `libs/mediapipe/` 包含 `vision_bundle.mjs`、`wasm/`、`selfie_segmenter.tflite` 與 `blaze_face_short_range.tflite`。

## 驗證

在專案根目錄執行：

```text
node assets/i18n.test.js
node --test effects/exploding-head/effect.test.mjs
```

29 項自動測試保留充氣、構圖、權限、生命週期、薄片物理、最大尺寸、同按鈕與甩動驗證；新增臉框裁切、實心貼圖 alpha、可靠頸色與冷色衣領排除、固定不規則破口與肩膀保護。失追保留破口、重置清除破口及頸色亦納入原互動測試。

本次已在 Chrome 用真人影像確認五官佔滿球體、細球底與原頸色銜接、爆炸破口及同按鈕重置；另以合成人像放大檢查接縫。實際 WebGL 像素檢查確認球內沒有透明孔洞。相機 Permissions Policy 封鎖時顯示繁中錯誤；只允許本機資源的 CSP 頁面重新載入後，相機、模型與打氣均可使用（未停用作業系統網路介面）。`thumb.png` 已更新為本次真人效果截圖。

這些檢查不代表所有裝置、髮型與光線都能精準裁切。
