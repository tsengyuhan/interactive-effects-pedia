# 爆炸頭

你的五官貼滿有曲面光影的立體氣球，綁在路邊紅色消防栓上。氣球受浮力、柔和風力與移頭慣性擺動；打氣會彈性膨脹，到達上限後碎成不規則薄片飄落，失去浮力的繩子垂下。主畫面不顯示真人肩頸或身體。

## 操作與限制

- 一個人正對鏡頭，讓五官完整入鏡。左右移頭可帶動氣球甩動；鏡頭距離不影響場景比例。
- 點擊下方「打氣」，預設 12 下到頂；等待視覺膨脹接近上限才爆炸。同一按鈕變成「重置」，沒有偵測到臉也能重玩。
- 資訊面板可調背景顏色、充氣速度（0.5–2 倍，約 24–6 下）、氣球最大尺寸（場景基準球體的 1.5–4 倍，預設 2.35）。改上限保留當次氣量，僅改變球體膨脹與爆炸門檻，絕不縮小或移動消防栓來容納氣球。極大氣球可超出畫面。
- 初次尚未偵測到臉時先顯示路面與消防栓。無臉、多臉或相機停幀時暫停打氣，已有的臉部貼圖保留在飄動氣球上；重新辨識後恢復即時五官。爆炸後不會因找回臉而自行復原。
- 載入、錯誤、背景分頁及充滿等待爆炸時禁用打氣；切到背景暫停動畫與推論。音效由 Web Audio 合成，不需要麥克風。
- 以單人正面為基準。側臉、遮擋、極暗光線或背景分割錯誤可能造成貼圖失真；不是完整 3D 臉部重建。

## 技術與需求

使用既有 MediaPipe Tasks Vision 0.10.14 的 ImageSegmenter 與 FaceDetector，CPU 推論、原生 WebGL 球面著色及 Canvas 2D 場景，沒有新增依賴或外部素材。兩模型讀取同一張最多 640 像素寬的相機快照。前景遮罩只用於臉部紋理，不將原始相機影像或身體合成至主畫布。

臉部框略留額頭與下巴，裁成固定 256×256，僅在貼圖時水平鏡像一次；五官放大包覆整顆球。遮罩空隙只由有效前景 RGB 補滿，球內 alpha 不透明。固定 512×512 離屏 WebGL 以球面法線、曲面 UV、方向光與高光呈現立體感；底端收成短氣嘴，接上小結與繩索，沒有頸部接片。

`scene.mjs` 依視窗尺寸安排場景基準大小、消防栓、綁點與繩長，與臉框、氣量、最大尺寸完全分離。路緣、鋪面、接觸陰影與金屬消防栓由 Canvas 2D 原生繪圖組成，管口、柱體、頂蓋與繩圈依前後順序遮擋。

繩子由 13 個 Verlet 節點組成，固定底端並反覆約束每段長度。末端浮力與柔和風力牽引球體，臉部左右位移驅動阻尼角彈簧，將慣性傳入繩索；球體方向跟隨末段繩子的張力並延遲回穩。爆炸移除浮力，繩索受重力回落，路面限制其下落。重置重新綁好；失追、重獲、相機尺寸改變與切分頁會清除追蹤輸入，避免座標跳躍造成暴衝。這是輕量的繩索動力學近似，沒有消防栓碰撞、空氣流體或完整剛體模擬。

爆炸時凍結已著色球面，32 個隨機 Voronoi 區域形成大小不一的薄片，直接沿用球體的畫面位置與角度，並帶入繩端速度。粒子受重力、朝向與面積／質量相關阻力、側向飄擺及角速度阻尼影響；翻面收成細線，約 4.6–6.7 秒依序淡出。

每次推論即釋放 mask 結果，離頁關閉模型、相機、音訊、RAF 與 GPU 貼圖／shader／buffer，包含初始化途中離頁。

- 攝影機；不需麥克風。
- 建議 Chrome／Edge，需 WebGL 與硬體加速；不支援時顯示明確錯誤。手機或較舊裝置雙模型推論可能較慢，沒有保證幀率。
- 必須透過 localhost 或 HTTPS，不能直接以 `file://` 開啟。
- 模型、WASM、程式均在專案內；下載完整專案後可在本機無外網執行，不代表線上網站有 Service Worker 離線快取。

## 下載到自己的電腦

1. `git clone https://github.com/tsengyuhan/interactive-effects-pedia.git`，或由 GitHub Download ZIP 後解壓縮。
2. 雙擊專案根目錄 `start.bat`。
3. 開啟 `http://localhost:8080/effects/exploding-head/`，允許攝影機權限。
4. 確認 `libs/mediapipe/` 包含 `vision_bundle.mjs`、`wasm/`、`selfie_segmenter.tflite` 與 `blaze_face_short_range.tflite`。

## 驗證

```text
node --test effects/exploding-head/effect.test.mjs
node assets/i18n.test.js
```

28 項效果測試涵蓋充氣門檻、追蹤暫停、相機權限與資源釋放、GPU 失敗清理、臉框與實心貼圖、薄片物理、同按鈕重置、移頭甩動，以及新場景的繩長／端點／有限值、爆後落繩、球結銜接及桌面與手機初始可見性。互動回歸確認 1.5→4→1.5 只改球體尺寸；失追、重置與相機尺寸改變均不調整消防栓構圖。主畫布的影像輸出只允許球面和凍結球面的碎片，沒有身體或原始 video。

Chrome 真人攝影機已確認主畫面僅有臉部氣球，12 下爆炸時薄片位置正確、消防栓固定、繩索垂下。桌面與 390×580、844×390 畫面確認球體、消防栓底座及控制區完整可見。相機 Permissions Policy 拒絕時顯示繁中錯誤；只允許本機資源的 CSP 頁面也成功載入新場景、相機與模型（未停用作業系統網路介面）。`thumb.png` 已更新為新版真人 67% 氣量的 800×510 截圖。這些檢查不代表所有裝置與光線都能精準裁切。
