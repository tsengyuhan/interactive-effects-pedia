# 聲音煙火

對著麥克風打鼓、拍手或發聲，畫面下方就發射一發煙火。有兩種視覺風格可以切換：

- **貓咪煙火**：純黑背景。一顆寫實貓咪頭往上飛、逐漸變大、逐格演出牠的動作，到最高點時整張臉碎成細點狀的粒子雲、定格成貓頭的形狀，然後才散開成火花。
- **紙張破裂煙火**：背景是一張白紙。一道鉛筆線往上畫出煙火升起的軌跡，到最高點時紙從線的末端被撕開一個破口，邊上掀起大塊紙片，露出後面流動的全息大理石動畫。撐一下之後整段撕開的動作原樣倒放，紙就合回去了。鉛筆的痕跡留在紙上，過幾秒才慢慢變淡。

## 主要技術

- Web Audio API
- getUserMedia
- Canvas 2D
- 逐格動畫

## 運作方式

- **起音偵測**：麥克風波形算 RMS 音量，只在音量「跨過」觸發門檻的那一瞬間發射，避免長音一直噴。90 毫秒不應期讓連續鼓點可以連發。
- **音高 → 高度**：用頻譜重心（spectral centroid）當聲音明亮度的近似，高頻聲音（銅鈸、拍手）飛得高，低頻（大鼓）飛得低。比自相關法便宜，對打擊樂也更穩。
- **音量 → 規模**：音量決定發射體大小與炸開時的粒子數量。最小聲跟最大聲差到 4 倍以上，一眼就分得出來。
- **上升的加速度**：位置用 smootherstep 而不是等速或線性減速——慢起步、中段最快、到頂點前收住，才有「衝上去然後停在最高點」的手感。整段只有 520 毫秒，慢了就沒有煙火往上衝的勁。
- **逐格感**：整套模擬固定跑 12 fps，不是 60 fps。6 張貓咪序列圖依飛行進度換格，刻意保留停格動畫的頓挫。
- **隨機抽貓**：每次發射從四隻貓裡隨機抽一隻，動作跟著那隻貓走。
- **不染色**：貓咪保留原本的毛色，才看得出品種；煙火顏色只作用在火星與貓咪外圍的輝光上。

## 貓咪怎麼炸成煙火

要的是「圖片 → 煙花 → 貓咪的形狀 → 散開」三段，所以爆炸不是換一組粒子，而是**從貓咪這張圖長出來的**：

1. **取樣**：到頂點時把當格的貓咪圖畫進一張 56×56 的離屏畫布，每個不透明像素換成一顆粒子，並帶著那個像素的原始毛色。格子切得夠細，散開才是細點狀的雲而不是一塊塊馬賽克。
2. **定格**：粒子先停在原位兩格不動也不衰減，畫成剛好填滿的方塊，拼成一整面看得出五官明暗的貓頭剪影。格子畫得比實際大 6%，才不會留下黑縫。
3. **散開**：定格一結束就改畫圓點、切換成疊加混色，離中心越遠的粒子飛越快，貓頭的形狀會先撐大再散掉。同一格才放出放射狀的乾筆筆觸，補上「爆」的衝擊感。

粒子的疊加混色在重疊處會爆白，所以不透明度隨壽命掉得比線性快，散開後才回得到毛色。

## 紙張是怎麼破的

洞完全是程式畫的，沒有用到任何圖檔或影片。參考真實的撕紙影片後，會發現關鍵不是洞本身，而是**掀起來的紙片與它們打在紙面上的影子**：

- **紙**：米白底、幾團大範圍極低對比的明暗不均、短而淡的纖維線，再灑一層細顆粒。紙只畫一次，resize 才重畫。
- **撕開**：破口從鉛筆線的末端開始，半徑從 0 等比長大到滿，用 smoothstep 讓它起步猛、收尾緩，像紙被一下子扯開。
- **洞的輪廓**：7~11 個頂點的多邊形，半徑在 0.84~1.14 倍之間晃，只有約四成五的邊會再撕出一根毛刺。頂點多或每個頂點都加齒就會變成齒輪或星星；改用圓滑曲線又會把撕裂的尖角磨成花瓣，所以是直線相連。
- **翻起來的紙片**：沿邊挑約七成的段落，兩端各沿自己的角度往外推成四邊形，外緣用二次曲線收邊。掀起的幅度刻意兩極化（四成幾乎不掀、六成掀很開），每片都一樣就會排成花瓣。形狀在破洞當下就決定好，每格重算會讓紙片一直抖。
- **影子**：同一片紙往右下位移、加模糊的複本。路徑上的點在加進去的當下就換算成畫面座標了，所以位移必須寫進座標裡，畫完再 `translate` 是不會動的。
- **合回去**：不是壓扁，是把整段撕開的動作原樣倒放，半徑再從滿收回 0。
- **洞後面的循環動畫**：全息大理石的流動——46 條相位錯開的珍珠白寬帶，每條下緣壓一道黑色深溝當骨架，另一側帶一條青／粉／綠的虹光細邊。粗細與色相都用三角函數算，不能用亂數，否則每格會閃。
- **動畫不隨洞縮放**：clip 出洞形後把變換重設回畫面座標再貼上那張全螢幕的流動圖，所以洞怎麼開合，後面的畫面都不動——就像前面蓋著一張紙。

鉛筆筆跡是沿路徑密集撒碳粉顆粒（兩個亂數相加逼近常態分布，顆粒才會集中在筆芯中央），而且只把新的那一段畫進鉛筆層、畫過的就固定在紙上。整層每格用 `destination-out` 擦掉一點點，痕跡就會一起慢慢變淡。

## 其他畫法上的細節

- **火星是筆觸不是光點**：每顆火星記三根「鬃毛」的偏移與長度，畫成一撇分岔的乾筆，長度隨速度收縮；撇尾另外甩出橢圓顏料點。靠近爆心接近白熱、尾端才回到煙火色。
- **拖尾**：貓咪風格每格用 26% 的黑覆蓋畫面，舊筆觸慢慢沉回黑底。紙張風格不做拖尾，每格整張重畫，紙才乾淨。

貓咪畫在自己的圖層、每格清空，才不會被拖尾糊掉。

## 素材

`frames/` 內是四隻寫實貓，每隻一套 6 格連續動作，512×512 透明底 WebP（24 張共約 1MB；同樣內容存成 PNG 要 6.7MB）：

| 檔名 | 貓 | 動作 |
|---|---|---|
| `tabby-01` ~ `06` | 橘虎斑 | 張嘴喵叫 |
| `tuxedo-01` ~ `06` | 賓士貓 | 生氣哈氣 |
| `ragdoll-01` ~ `06` | 布偶貓 | 受驚嚇（瞳孔放大、耳朵後倒） |
| `siamese-01` ~ `06` | 暹羅貓 | 歪頭好奇 |

同一組 6 格是同一隻貓，只有動作在變，所以連著播才像在動而不是在換貓。四組的臉都朝向鏡頭，沒有轉頭或側面。

## 可調參數

- 視覺風格（貓咪煙火／紙張破裂煙火）
- 觸發音量（-55 ~ -10 dB）
- 煙火大小（0.5 ~ 2 倍，也決定破洞多大）
- 煙火顏色（紙張風格影響洞裡那段全息流動的色相）
