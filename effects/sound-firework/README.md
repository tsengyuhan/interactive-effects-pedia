# 聲音煙火

對著麥克風打鼓、拍手或發聲，純黑的畫面下方就發射一發煙火。有兩種視覺風格可以切換：

- **貓咪煙火**：一顆寫實貓咪頭往上飛、逐漸變大、逐格演出牠的動作，到最高點時整張臉碎成粒子、定格成貓頭的形狀，然後才散開成火花。
- **數位雜訊**：一束由掃描線構成的訊號柱往上飛，越接近頂點錯位越亂，炸開時撕成橫向條紋與馬賽克方塊，帶青／洋紅色差，然後迅速消逝。

## 主要技術

- Web Audio API
- getUserMedia
- Canvas 2D
- 逐格動畫

## 運作方式

- **起音偵測**：麥克風波形算 RMS 音量，只在音量「跨過」觸發門檻的那一瞬間發射，避免長音一直噴。90 毫秒不應期讓連續鼓點可以連發。
- **音高 → 高度**：用頻譜重心（spectral centroid）當聲音明亮度的近似，高頻聲音（銅鈸、拍手）飛得高，低頻（大鼓）飛得低。比自相關法便宜，對打擊樂也更穩。
- **音量 → 規模**：音量決定發射體大小與炸開時的粒子數量。最小聲跟最大聲差到 4 倍以上，一眼就分得出來。
- **逐格感**：整套模擬固定跑 12 fps，不是 60 fps。6 張貓咪序列圖依飛行進度換格，刻意保留停格動畫的頓挫。
- **隨機抽貓**：每次發射從四隻貓裡隨機抽一隻，動作跟著那隻貓走。
- **不染色**：貓咪保留原本的毛色，才看得出品種；煙火顏色只作用在火星與貓咪外圍的輝光上。

## 貓咪怎麼炸成煙火

要的是「圖片 → 煙花 → 貓咪的形狀 → 散開」三段，所以爆炸不是換一組粒子，而是**從貓咪這張圖長出來的**：

1. **取樣**：到頂點時把當格的貓咪圖畫進一張 30×30 的離屏畫布，每個不透明像素換成一顆粒子，並帶著那個像素的原始毛色。
2. **定格**：粒子先停在原位兩格不動也不衰減，畫成剛好填滿的方塊，拼成一整面看得出五官明暗的貓頭剪影。格子畫得比實際大 6%，才不會留下黑縫。
3. **散開**：定格一結束就改畫圓點、切換成疊加混色，離中心越遠的粒子飛越快，貓頭的形狀會先撐大再散掉。同一格才放出放射狀的乾筆筆觸，補上「爆」的衝擊感。

粒子的疊加混色在重疊處會爆白，所以不透明度隨壽命掉得比線性快，散開後才回得到毛色。

## 其他畫法上的細節

- **火星是筆觸不是光點**：每顆火星記三根「鬃毛」的偏移與長度，畫成一撇分岔的乾筆，長度隨速度收縮；撇尾另外甩出橢圓顏料點。靠近爆心接近白熱、尾端才回到煙火色。
- **拖尾**：每格用半透明黑覆蓋畫面，舊筆觸慢慢沉回黑底。雜訊風格要的是「爆發又消失」，覆蓋加重到 62%，幾乎不留殘影。
- **雜訊風格的訊號柱**：一束水平掃描線，每條的長度、位移與亮度都隨機，越接近頂點錯位幅度越大。青（185°）與洋紅（315°）各畫一份偏移的重影做出色差，中間那份主體壓暗一點，不然疊加混色會把三份洗成一片白。

貓咪與訊號柱畫在自己的圖層、每格清空，才不會被拖尾糊掉。

## 素材

`frames/` 內是四隻寫實貓，每隻一套 6 格連續動作，512×512 透明底 WebP（24 張共約 1MB；同樣內容存成 PNG 要 6.7MB）：

| 檔名 | 貓 | 動作 |
|---|---|---|
| `tabby-01` ~ `06` | 橘虎斑 | 張嘴喵叫 |
| `tuxedo-01` ~ `06` | 賓士貓 | 生氣哈氣 |
| `ragdoll-01` ~ `06` | 布偶貓 | 受驚嚇（瞳孔放大、耳朵後倒） |
| `siamese-01` ~ `06` | 暹羅貓 | 歪頭好奇 |

同一組 6 格是同一隻貓，只有動作在變，所以連著播才像在動而不是在換貓。四組的臉都朝向鏡頭，沒有轉頭或側面。

## 可調參數

- 視覺風格（貓咪煙火／數位雜訊）
- 觸發音量（-55 ~ -10 dB）
- 煙火大小（0.5 ~ 2 倍）
- 煙火顏色（雜訊風格只影響主體色，青／洋紅色差固定）

## 需求

- 麥克風
- 建議 Chrome / Edge

- 需經 `start.bat` 或 HTTPS 開啟
