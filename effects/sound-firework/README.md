# 聲音煙火

對著麥克風打鼓、拍手或發聲，畫面下方就發射一發煙火。有兩種視覺風格可以切換：

- **貓咪煙火**：純黑背景。一顆寫實貓咪頭拖著一道連續的尾巴往上飛、逐漸變大、逐格演出牠的動作，到最高點時一邊繼續放大一邊化成點狀剪影，接著粒子再往外聚成一個更大的貓頭輪廓，最後才散成稀疏的點雲。
- **紙張破裂煙火**：背景是一張白紙。一道色鉛筆線從畫面最底下一口氣甩上去，畫出煙火升起的軌跡，到最高點時紙從線的末端被撕開一個破口，四周同時甩出幾筆彩色短觸當成綻放的火花，邊上掀起大塊紙片，露出後面黑白流體潑漆＋全息虹光的動畫。撐一下之後整段撕開的動作原樣倒放，紙就合回去了。色鉛筆的痕跡留在紙上，過幾秒才慢慢變淡。每一發隨機抽一個顏色和一支粗細，像從一盒色鉛筆裡輪流挑。
- **只看背景動態**：把前面的煙火整個關掉，破口後面那層流體直接鋪滿畫面。這個模式下離屏圖從 480×600 加大到 960×1200 才不會糊。

## 主要技術

- Web Audio API
- getUserMedia
- Canvas 2D
- 逐格動畫

## 運作方式

- **起音偵測**：麥克風波形算 RMS 音量，只在音量「跨過」觸發門檻的那一瞬間發射，避免長音一直噴。90 毫秒不應期讓連續鼓點可以連發。
- **音高 → 高度**：用頻譜重心（spectral centroid）當聲音明亮度的近似，高頻聲音（銅鈸、拍手）飛得高，低頻（大鼓）飛得低。比自相關法便宜，對打擊樂也更穩。
- **音量 → 規模**：音量決定發射體大小與炸開時的粒子數量。最小聲跟最大聲差到 4 倍以上，一眼就分得出來。
- **上升的加速度**：貓咪用 smoothstep、520 毫秒——慢起步、中段最快、到頂點前收住，才有「衝上去然後停在最高點」的手感。用更陡的 smootherstep 的話尾段幾乎靜止，看起來像突然按了暫停。
- **色鉛筆線是一記快甩**：170 毫秒，而且改用 ease-out（`1 - (1-p)^2.4`）——起手就是最快，尾段才收住；smoothstep 的慢起步看起來像在描而不是在甩。起筆點是畫面底緣外側，第一格就從那裡開始畫，線才不會離畫面下緣有一段空白。一格拆成四小段畫，甩得快也不會斷成折線。筆壓由重到輕收出筆鋒。
- **畫布跟著螢幕像素密度走**：backing store 乘上 `devicePixelRatio`（封頂 2，粒子數以千計再高就掉格），再用 `setTransform` 把座標系縮回 CSS 像素，畫圖的程式碼一行都不用改。沒做這件事的話高 DPI 螢幕上整層會被瀏覽器拉伸，貓咪照片就會看起來像低解析度。原圖本身是 512×512，音量很大時的最終尺寸會超過它，那部分只能換更大的素材。
- **逐格感**：整套模擬固定跑 12 fps，不是 60 fps。6 張貓咪序列圖依飛行進度換格，刻意保留停格動畫的頓挫。
- **隨機抽貓**：每次發射從四隻貓裡隨機抽一隻，動作跟著那隻貓走。
- **不染色**：貓咪保留原本的毛色，才看得出品種；煙火顏色只作用在尾巴與貓咪外圍的輝光上。

## 貓咪怎麼炸成煙火

爆炸不是換一組粒子，而是**從貓咪這張圖長出來的**，全程粒子數量不變，只是重新排列：

1. **取樣**：到頂點時把當格的貓咪圖畫進一張 56×56 的離屏畫布，每個不透明像素換成一顆粒子，並帶著那個像素的原始毛色。格子切得夠細，散開才是細點狀的雲而不是一塊塊馬賽克。
2. **綻放交棒**：接下來四格，照片不停在頂點，而是繼續放大到 1.3 倍並淡出；粒子剪影用同一條放大曲線同步脹大並淡入，畫成剛好填滿的方塊（比實際大 6%，才不會留下黑縫），拼成一整面看得出五官明暗的貓頭。兩者交疊，所以看到的是「照片一邊脹大一邊化成粒子」。早期版本是到頂點原地定格再切成剪影，中間那一格的停頓看起來就像卡了一下。
3. **聚成輪廓**：先量出每個角度上貓頭最外緣的半徑，得到一圈輪廓；接下來三格，每顆粒子都從剛剛脹到的位置往自己那個角度的輪廓跑，聚成一個放大 1.55 倍的貓頭形狀——放大是一路連續的，沒有中斷。這段不衰減也不吃重力，形狀才撐得住。
   輪廓的半徑只跟左右鄰居取平均——取最大值會把耳朵旁邊的凹陷一起抬平，輪廓就變成一個橢圓、看不出是貓頭了。
4. **散開**：從輪廓往外飛，越散越稀疏。

粒子的疊加混色在重疊處會爆白，所以不透明度大半輩子維持滿值、最後才快速掉，數量看起來才是不變的。

上升的尾巴是每格把新走過的線段接上去畫，舊的靠拖尾自己淡掉；每格灑幾筆散點會斷成一節一節的。

## 紙張是怎麼破的

破口原本是程式畫的多邊形，怎麼調都不夠自然（不是變齒輪就是變花瓣），最後改成**播放序列圖**：

- **紙**：米白底、幾團大範圍極低對比的明暗不均、短而淡的纖維線，再灑一層細顆粒。紙只畫一次，resize 才重畫。
- **撕開序列**：四種撕法，每種 6 格從小裂口撕到滿。發射時隨機抽一組，破口從色鉛筆線的末端長出來。四組都是不規則的歪斜輪廓——做過圓形／縱向／橫向的版本，太規矩，尤其圓形那組像用圓規畫的。
- **合回去**：不是淡出也不是壓扁，就是把這 6 格**原樣倒放**。整段是撕開 6 格 → 撐 2 格 → 倒放 6 格，而且用 1.6 倍速跳著播，破口才有炸開的乾脆感。
- **綻放的火花**：破口一出現就在四周甩出 10～18 筆彩色短觸，每筆拆成兩段並帶一點弧度（放射狀的直線太像太陽圖案），色相繞著這一發的主色 ±45 度散開。一次全部畫完——破口本身只開合幾格，線條慢慢長出來反而拖住節奏。
  - 筆觸是**短而粗**：起點推到破口邊緣（`inner` 取 0.8～1.0 倍半徑）而不是從洞中央拉出來，長度就短了；筆芯用 `nib × 1.2` 加粗。細長的版本看起來像太陽光芒，不像炸開的火花。
- **貼片只留紙片與影子**：後製時把平坦的紙面整片變透明，只保留掀起來的紙片與它們的影子。留著紙面的話貼片會蓋掉底下的鉛筆線（線會在接近洞口處憑空消失），方形貼片的邊界也會露出接縫。
- **洞後面的循環動畫**：黑底上的灰銀湍流，邊緣泛出霓虹虹光。這層是**唯一用 WebGL 的部分**——每個像素都要各自算域變形雜訊，Canvas 2D 逐像素在 12fps 下跑不動。細節見下一節。
- **動畫不隨洞縮放**：用破口遮罩把流動圖 `source-in` 剪成洞形，取的是畫面上同一塊區域，所以洞怎麼開合後面的影像都不動——就像前面蓋著一張紙。

色鉛筆筆跡是沿路徑密集撒顆粒（兩個亂數相加逼近常態分布，顆粒才會集中在筆芯中央），中央濃、邊緣淡。只把新的那一段畫進鉛筆層、畫過的就固定在紙上。整層每格用 `destination-out` 擦掉一點點，痕跡就會一起慢慢變淡。

顏色有兩件事要注意：

- **亮度要訂在中間偏亮**（`lerp(72, 54)`）。同一個點會被幾十顆半透明顆粒疊到，疊加後只會越來越暗；起始亮度訂低的話整條線最後會變成看不出色相的深色，每一發都長得一樣。
- **色相切成 12 支筆去抽**，不用 `random(0, 360)` 連續亂數——連續亂數常常抽到相鄰的色相，兩發看起來就像同一支筆。
- **筆芯粗細也隨機**（`nib`）：一半維持原本的細筆，另一半抽 1.5～2.6 倍的粗筆。顆粒數要跟著一起加，不然粗筆只是把同樣的顆粒撒得更散，變成一條稀疏的霧而不是一條粗線。

## 洞後面那層流體

參考的是黑白流體潑漆＋全息虹光那種質感。整層是一支 fragment shader，每格重畫一張離屏圖：

- **域變形（domain warping）**：拿一層 fbm 的輸出去偏移下一層的取樣座標，做兩輪。平行的紋路會被扭成漩渦——**這是湍流感唯一的來源**，少了它就只是一團雲。fbm 用四層就夠，再多層只是在已經被扭爛的圖上加看不見的細節。
- **不用門檻切「有沒有流體」**：整片都是流體，只是調子從近黑到亮白連續變化。取值範圍（`smoothstep(0.10, 0.78, f)`）刻意開得比 fbm 實際範圍寬、不裁掉兩端，gamma 也只用 1.2。這樣暗部仍然看得到流動的紋理，而不是一大片純黑的空洞。先前用 `smoothstep(0.40, 0.66)` 當門檻，畫面會空掉一半。
- **本體是灰銀不是白**：另一組低頻起伏 `shade` 做內部深淺，少了它會變成一塊死白的剪影。另外壓一道很窄的白線當液態金屬的高光稜線。
- **離屏圖固定 0.8 的直式比例，再拉伸貼滿畫面**。寬螢幕上的橫向拉伸是刻意的——紋理被拉長才有流體被拖開的感覺。改成跟著畫面比例走試過，紋理會變得細碎，反而不像。
- **虹光要用遮罩控制分布**：遮罩頻率訂太低（試過 `p * 0.5`）整張圖只會有一兩塊彩虹擠在角落。現在是 `p * 1.3` 配 `0.3/0.5` 的門檻——頻率決定散得多開，門檻決定總量。
- **上色前要先把底下的灰壓掉**（`col *= 1.0 - 0.8 * amount`）。彩虹直接加在白色上只會被洗成粉彩；目標是彩虹「取代」那塊流體的顏色，不是疊在上面。
- 這幾組數值（調子的 `0.10/0.78` 與 gamma `1.2`、取樣尺度 `3.6/2.4`、遮罩的 `1.3` 頻率與 `0.3/0.5` 門檻、band 寬度 `0.050/0.028`）是把同一套數學在 Node 上用 CPU 跑成 PNG、對著參考圖調出來的，改之前先確認要往哪個方向偏。

沒有 WebGL 的話這層留白，破口的紙片動畫本身還是照跑。

## 其他畫法上的細節

- **拖尾**：貓咪風格每格用 26% 的黑覆蓋畫面，尾巴與粒子慢慢沉回黑底。紙張風格不做拖尾，每格整張重畫，紙才乾淨。
- **只看背景動態**：`launch()` 直接 return 不生成火箭，`draw()` 把流體圖鋪滿畫面就結束，不必為了關掉煙火再開一組狀態。
- **沒破口就不算流體**：紙張風格下若畫面上一個洞都沒有，那層 shader 就不跑。它停在原格再接著跑也看不出接縫。

貓咪畫在自己的圖層、每格清空，才不會被拖尾糊掉。

## 素材

`frames/` 內是四隻寫實貓，每隻一套 6 格連續動作，512×512 透明底 WebP：

| 檔名 | 貓 | 動作 |
|---|---|---|
| `tabby-01` ~ `06` | 橘虎斑 | 張嘴喵叫 |
| `tuxedo-01` ~ `06` | 賓士貓 | 生氣哈氣 |
| `ragdoll-01` ~ `06` | 布偶貓 | 受驚嚇（瞳孔放大、耳朵後倒） |
| `siamese-01` ~ `06` | 暹羅貓 | 歪頭好奇 |

同一組 6 格是同一隻貓，只有動作在變，所以連著播才像在動而不是在換貓。四組的臉都朝向鏡頭，沒有轉頭或側面。

撕紙序列是 `tear-{a,b,c,d}-01` ~ `06`，四種不規則撕法各 6 格。每格兩個檔：

- `tear-a-01.webp`：掀起的紙片與影子，平坦紙面透明
- `tear-a-01-m.webp`：破口遮罩，用來把後面的流動圖剪成洞的形狀

原始圖是白紙加純綠幕破口，後製時從中心 flood fill 找出破口（只看綠色不行，紙面外緣也可能有綠溢色），
再算出遮罩、把紙色校正成程式畫的紙色，並用亮度差把平坦紙面整片轉成透明。48 個檔共約 600KB。

## 可調參數

- 視覺風格（貓咪煙火／紙張破裂煙火／只看背景動態）
- 觸發音量（-55 ~ -10 dB）
- 煙火大小（0.5 ~ 2 倍，也決定破洞多大）
- 煙火顏色（貓咪的尾巴與輝光；紙張風格是那層流體虹光的相位起點。色鉛筆本身不受它影響，是每發從 12 支筆裡隨機抽）

貓咪的最終大小是三段相乘：`launch()` 的 `0.16`（螢幕短邊比例）× 音量對應的 `lerp(0.42, 1.85, …)` ×
`drawCat()` 的 `lerp(0.4, 1, eased)`，到頂點後再乘 `BLOOM_SCALE`（1.3），粒子輪廓再到 `RIM_SCALE`（1.55）。
要整體放大改 `0.16`，要拉大音量落差改那組 `lerp`。
