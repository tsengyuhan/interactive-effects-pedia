# 聲音煙火

對著麥克風打鼓、拍手或發聲，畫面下方就發射一顆貓咪頭。貓咪一路往上飛、逐漸變大，表情逐格變化，飛到最高點時綻放成煙火筆觸後淡出。整體走油畫插畫風：筆觸明顯、細節少、奔放自由。

## 主要技術

- Web Audio API
- getUserMedia
- Canvas 2D
- 逐格動畫

## 運作方式

- **起音偵測**：麥克風波形算 RMS 音量，只在音量「跨過」觸發門檻的那一瞬間發射，避免長音一直噴。90 毫秒不應期讓連續鼓點可以連發。
- **音高 → 高度**：用頻譜重心（spectral centroid）當聲音明亮度的近似，高頻聲音（銅鈸、拍手）飛得高，低頻（大鼓）飛得低。比自相關法便宜，對打擊樂也更穩。
- **音量 → 規模**：音量決定貓咪大小與炸開時的火星數量。
- **逐格感**：整套模擬固定跑 12 fps，不是 60 fps。6 張貓咪序列圖依飛行進度換格，刻意保留停格動畫的頓挫。
- **染色**：貓咪原圖畫成淺奶油色，程式用 `source-atop` 疊上煙火顏色，所以顏色參數可以直接改變貓咪與火星的色調。

## 畫成油畫的做法

視覺參考的是厚塗油畫煙火：深藍夜空、放射狀的乾筆長筆觸、金色顏料點。三件事讓 Canvas 看起來像畫的：

- **夜空是刷出來的**：深藍底上用方頭粗筆（`lineCap = "butt"`）朝同一個主方向反覆疊塗兩百多筆，再加細筆刮痕與金／白顏料點。圓頭粗線會變成一根根膠囊，所以用方頭。夜空只畫一次，resize 才重畫。
- **火星是筆觸不是光點**：每顆火星記三根「鬃毛」的偏移與長度，畫成一撇分岔的乾筆，長度隨速度收縮；撇尾另外甩出橢圓顏料點。靠近爆心接近白熱、尾端才回到煙火色。
- **殘筆淡回夜空**：每格不是疊黑色，而是把夜空本身以 24% 不透明度覆蓋上去，舊筆觸會化進背景而不是壓成死黑。

貓咪畫在自己的圖層、每格清空，才不會被拖尾糊掉。

## 素材

`frames/cat-01.png` ~ `cat-06.png` 是同一隻貓的 6 格表情序列（平靜 → 半睜眼 → 驚訝 → 興奮 → 大笑 → 極度開心），512×512 透明底 PNG。畫風是大筆乾刷、破碎的毛邊、五官只用少量不對稱的深色筆痕。

## 可調參數

- 觸發音量（-55 ~ -10 dB）
- 煙火大小（0.5 ~ 2 倍）
- 煙火顏色

## 需求

- 麥克風
- 建議 Chrome / Edge
- 無特殊效能需求
- 需經 `start.bat` 或 HTTPS 開啟
- 可離線使用

## 在自己電腦使用

1. 下載整個專案：
   - `git clone https://github.com/tsengyuhan/interactive-effects-pedia.git`
   - 或在 GitHub 頁面 Download ZIP 後解壓
2. 啟動方式：
   - 雙擊專案根目錄的 `start.bat`
   - 瀏覽器開 `http://localhost:8080/effects/sound-firework/`
3. 這個效果需要麥克風權限，必須用 `start.bat` 啟動，或透過 HTTPS 開啟。
